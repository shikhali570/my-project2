# سامانه حسابداری تحت وب (PHP)

یک نرم‌افزار حسابداری کامل و سبک با **PHP خالص** و **MySQL**، با رابط کاربری **فارسی و راست‌چین**، مناسب شرکت‌ها، فروشگاه‌ها و کسب‌وکارهای کوچک.

---

## ✨ امکانات

### منوی اصلی
| بخش | توضیح |
|------|--------|
| **داشبورد** | موجودی صندوق/بانک، مطالبات و بدهی‌ها، فروش و خرید ماه، سود خالص، نمودار شش‌ماهه، آخرین اسناد |
| **اشخاص** | ثبت مشتریان و تأمین‌کنندگان، مانده اول دوره، مانده لحظه‌ای، جستجو |
| **اقلام و کالاها** | کد، نام، واحد، قیمت خرید/فروش، موجودی |
| **فاکتور فروش** | ثبت فاکتور با اقلام نامحدود، تخفیف، مالیات، سررسید، چاپ، پیگیری پرداخت |
| **فاکتور خرید** | مانند فاکتور فروش با حساب‌های خرید |
| **دریافت و پرداخت** | اسناد واریز/برداشت، اتصال به فاکتور، انتخاب صندوق یا بانک |
| **تنخواه و هزینه‌ها** | ثبت هزینه‌ها با انتخاب حساب هزینه و حساب پرداخت |
| **کدینگ حساب‌ها** | نمودار درختی حساب‌ها (دارایی، بدهی، سرمایه، درآمد، هزینه) با امکان ویرایش |
| **گزارش‌ها** | دفتر روزنامه، دفتر کل، تراز آزمایشی، سود و زیان، ترازنامه، مانده اشخاص، گزارش فاکتورها |
| **کاربران** | مدیریت کاربران و نقش‌ها (فقط مدیر) |
| **تنظیمات** | اطلاعات شرکت، درصد مالیات پیش‌فرض (فقط مدیر) |

### ویژگی‌های فنی
- **حسابداری دوطرفه**: هر فاکتور/سند به‌صورت خودکار در دفتر روزنامه ثبت می‌شود
- **تاریخ شمسی**: ورود و نمایش تاریخ‌ها به‌صورت جلالی (مثلاً `1404/07/20`)
- **سطوح دسترسی**: مدیر سیستم / حسابدار / کاربر ساده (مشاهده‌گر)
- **امنیت**: هش رمز عبور با `password_hash`، توکن CSRF در همه فرم‌ها، جلوگیری از XSS با خروجی امن
- **چاپ فاکتور و گزارش‌ها**: طرح چاپی تمیز با یک کلیک
- **بدون فریم‌ورک**: قابل استقرار روی هر هاست اشتراکی PHP

## 🚀 نصب

### ۱. پیش‌نیازها
- PHP نسخه ۸.۰ به بالا به‌همراه افزونه‌های `pdo_mysql` و `mbstring`
- MySQL یا MariaDB (یا SQLite برای تست بدون دیتابیس)

### ۲. ایجاد پایگاه داده
در phpMyAdmin یا هاست خود یک دیتابیس بسازید (مثلاً `accounting`) و سپس فایل
[`database/schema.sql`](database/schema.sql) را در آن اجرا کنید.

### ۳. پیکربندی
فایل [`config.php`](config.php) را ویرایش کنید:

```php
'db' => [
    'driver'   => 'mysql',
    'host'     => '127.0.0.1',
    'dbname'   => 'accounting',
    'username' => 'root',
    'password' => 'رمز_دیتابیس_شما',
    ...
],
```

> 💡 به‌جای دست زدن به `config.php` می‌توانید فایل `config.local.php` بسازید (در Git هم ثبت نمی‌شود) و فقط مقادیر دلخواه را در آن بازتعریف کنید؛ مقادیر این فایل بر `config.php` اولویت دارند.

### ۴. اجرای نصب‌کننده
مرورگر را روی `install.php` باز کنید و دکمه «شروع نصب» را بزنید:
- جداول ساخته می‌شوند
- کدینگ استاندارد حساب‌ها ثبت می‌شود
- کاربر مدیر ساخته می‌شود
- (اختیاری) داده‌های نمونه برای شروع سریع ایجاد می‌شوند

### ۵. ورود
به `login.php` بروید:

| نام کاربری | رمز عبور |
|:---:|:---:|
| `admin` | `admin123` |

> ⚠️ حتماً پس از اولین ورود، رمز عبور مدیر را تغییر دهید.

## 🗃️ پایگاه داده
نسخه اصلی **MySQL** است. برای اجرای دمو و تست بدون نصب MySQL کافی است در `config.php`:

```php
'driver' => 'sqlite',
```

را تنظیم کنید (یا اگر `allow_sqlite_fallback` فعال باشد و اتصال MySQL ممکن نباشد، برنامه خودکار به SQLite سوییچ می‌کند).

## ⚖️ معادله حسابداری
تمام اسناد (فاکتور، دریافت/پرداخت، هزینه، مانده اول دوره) به‌صورت خودکار سند دوطرفه ثبت می‌کنند؛ بنابراین گزارش‌های **تراز آزمایشی**، **سود و زیان** و **ترازنامه** همیشه با هم سازگارند.
